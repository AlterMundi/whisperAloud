# WhisperAloud STT Benchmark

Reproducible performance matrix: `language × model × engine × hardware`.
Metrics: WER, RTF (proc/audio), peak RAM/VRAM, model size, load time — with full
hardware provenance. See `MATRIX.md` for current results.

## Methodology & caveats
- Dataset: FLEURS (read-speech, CC-BY). Absolute WER is optimistic vs real mic
  dictation; **relative ordering across engines is the reliable signal.**
- WER normalization is identical for all engines (lowercase, no punctuation). It does
  NOT strip Spanish accents — both reference and hypothesis pass through the same
  transform, so it is fair, but engines that drop diacritics show a slightly higher floor.
- RTF is the median of `--reps` (default 3) timed passes.
- GPU numbers are machine-specific — always read `hw.id`. Nothing here is vendor-reported.

## Reproduce
```bash
source ~/.venvs/whisper_aloud/bin/activate
pip install -r bench/requirements-bench.txt
python -m bench.datasets.fleurs --lang es,en --n 40
# Parakeet model (gitignored) — download once:
curl -sL -o m.tar.bz2 https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2
tar xjf m.tar.bz2 -C bench/ && rm m.tar.bz2
python -m bench.runner \
  --engines "faster-whisper:small,parakeet:bench/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8" \
  --device auto
python -m bench.report   # regenerates MATRIX.md
```

## Hardware setup notes
- **CPU:** works out of the box.
- **NVIDIA:** install CUDA-enabled ctranslate2 + a `sherpa-onnx` GPU build; run with
  `--device cuda`. Or use `bench/scripts/run_remote.sh <host>` against a GPU box.
- **Intel iGPU (Vulkan):** build whisper.cpp with `-DGGML_VULKAN=1`, set `WHISPERCPP_BIN`
  to the `whisper-cli` binary, run `whispercpp:<path-to-gguf>` with `--device vulkan`.
- **AMD ROCm / Coral TPU:** schema-ready, not yet measured. Add an adapter under
  `bench/engines/experimental/` and a `device` value.

## Known gaps (iteration 1)
- **Parakeet on CUDA not yet measured.** The default `pip install sherpa-onnx` wheel is
  CPU-only, so a `--device cuda` Parakeet run silently falls back to CPU. The runner's
  VRAM integrity guard detects this (a cuda run that allocated no GPU memory) and **skips
  the row rather than mislabeling CPU numbers as GPU**. Measuring Parakeet on GPU needs a
  GPU-enabled sherpa-onnx build; tracked for a follow-up / WHISP-38.
- **whisper.cpp (Vulkan / Intel iGPU)** not yet measured — needs a local Vulkan build.

## Layout
- `src/whisper_aloud/stt/` — shared `STTEngine` interface + production engines
  (faster-whisper, Parakeet), consumed by both this benchmark and (later) the daemon.
- `bench/engines/` — registry + bench-local adapters (whisper.cpp) + `experimental/`.
- `bench/datasets/` — FLEURS fetcher + committed manifests (audio is gitignored).
- `bench/results/ledger.jsonl` — append-only results (committed); merge across machines
  by concatenating lines. `MATRIX.md` — generated by `python -m bench.report`.
